Formato de respuesta:

Este conector le permite cargar los datos de un indicador o de una instancia de indicador. Estos datos se publican originalmente a través de la API de Indicadores.

A la hora de seleccional los datos del indicador a cargar tiene varias opciones:

  1. Introducir la URL de los datos que desea cargar. Esta URL debe ser una petición de las que finalizan en "/data" de la API anteriormente mencionada.
  2. Navegador por distintos criterios para seleccionar el recurso que desea cargar.
