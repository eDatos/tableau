Seleccione los datos que desea obtener:

Este conector le permite cargar los datos de un dataset o una consulta. Estos datos se publican originalmente a través de la API de Recursos Estadísticos.

A la hora de seleccionar los datos a cargar disponemos de varias opciones:

  1. Introducir la URL de los datos que se desean cargar. Esta URL debe ser una petición para obtener un dataset o una query de la API. Además, en el caso de los datasets podrá hacer uso del parámetro "dim" para filtrar los datos a obtener y así reducir el tamaño de la respuesta.
  2. Navegar por operación estadística para seleccionar el dataset o query que desea cargar.
