## Arrancar proyecto

1. **mvn clean install** para instalar la versión de node y yarn correspondientes. Se está usando el plugin de maven [frontend-maven-plugin](https://github.com/eirslett/frontend-maven-plugin). (*lanzar desde la carpeta raíz del proyecto*)
2. **yarn http-server** levanta el proyecto.  (*lanzar desde src/main/resources/public/*)
